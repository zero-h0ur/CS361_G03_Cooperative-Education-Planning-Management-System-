# Coordinator และ Committee

ใช้ migrations 001–009 และ runtime grants รุ่นเดียวกับ Backend/Frontend ห้ามนำเฉพาะหน้าเว็บใหม่ขึ้นฐานข้อมูลที่ยังมีเพียง 001–003 และห้ามแก้ checksum ของ migration ที่ใช้แล้ว

Coordinator รับแผนที่ส่งแล้วเฉพาะรอบ ภาควิชา และหลักสูตรใน `selection_cohorts` ที่ตนรับผิดชอบ Committee เห็นผู้สมัครหลังรับแผนแล้ว และให้ความเห็นได้คนละหนึ่งครั้ง ผู้สมัครหนึ่งคนมีกรรมการที่กำหนดไว้สามคนต่างกัน ความเห็นทั้งเห็นชอบและไม่เห็นชอบนับเป็นการบันทึกครบ เมื่อครบสามคนสถานะเป็น `SELECTION_COMPLETE_PENDING_ANNOUNCEMENT` ยังไม่มีผลผ่าน/ไม่ผ่านหรือการประกาศผลอัตโนมัติ

การรับแผนและความเห็นเป็นประวัติที่แก้ทับไม่ได้ คำสั่งซ้ำใช้ operation ID เดิมได้ และตรวจสิทธิ์ปัจจุบันซ้ำทุกครั้ง ไม่เปลี่ยนสถานะอนุมัติของ Plan เดิม นักศึกษาเห็นเฉพาะความคืบหน้าของตน กรรมการเห็นเนื้อหาความเห็นของตนเองเท่านั้น

ผู้ดูแลเป็นผู้กำหนดรอบและกรรมการผ่านงานปฏิบัติการ ไม่มีสิทธิ์แก้แผงกรรมการหรือเปลี่ยนบทบาทผ่านหน้าเว็บของ Coordinator/Committee ไม่แทนสองบทบาทนี้ด้วย Staff/Advisor

## ขอบเขตที่ยังไม่รวม

- TU API และข้อมูลทะเบียนจริง
- GPAX เกรดเจ็ดวิชา เกณฑ์คุณสมบัติ และการจัดอันดับ
- การอัปโหลดหรืออ่านเนื้อหา CV, Transcript และรูปจริง
- สรุปว่าทุกผู้สมัครทั้งรอบครบสามความเห็น และการประกาศผล

Student ยังใช้การส่งแผนของ V3 ซึ่งมีชื่อโครงการและเอกสารอ้างอิงภายนอกตาม policy ที่เผยแพร่ การเพิ่มบทบาทนี้ยังไม่แทนแบบสมัคร Phase 1 ทั้งหมด รอบและบัญชีสาธิตต้องระบุชัดว่าเป็นข้อมูลจำลอง ห้ามใช้เป็นผลการศึกษาหรือผลคัดเลือกจริง

ฟอร์มแผนเปิดตัวกรอง “เฉพาะบริษัทที่มีตำแหน่งให้เลือก” เป็นค่าเริ่มต้น ยกเลิกตัวกรองได้หากต้องการดูทะเบียนทั้งหมด บริษัทที่ไม่มีตำแหน่งยังบันทึกฉบับร่างได้ แต่ส่งแผนไม่ได้จนกว่าจะเลือกตำแหน่งที่ถูกต้อง การมีประกาศในชุดข้อมูลไม่ยืนยันว่าปัจจุบันบริษัทยังเปิดรับ

## ตรวจสอบ

`npm run test:selection` ตรวจ role, API และ UI ส่วน integration ต้องตั้ง `CO_ED_SELECTION_TEST_DATABASE_URL` ไปยัง PostgreSQL ในเครื่อง ชื่อฐานข้อมูล `coed_selection_test` เท่านั้น ชุดทดสอบสร้าง schema และ role ชั่วคราวของตนและลบเมื่อเสร็จ ไม่ใช้ RDS หรือข้อมูลผู้ใช้จริง

ก่อนเปิดใช้งานต้องตรวจการ login จริงของแต่ละบทบาทแยกจากผล unit/integration และตรวจว่า anonymous เรียกเส้นทางใหม่ไม่ได้

ผลนำขึ้นบัญชีใหม่และสิ่งที่ยังต้องทดสอบอยู่ใน [หลักฐาน deployment](../evidence/selection-roles-deployment.md)
